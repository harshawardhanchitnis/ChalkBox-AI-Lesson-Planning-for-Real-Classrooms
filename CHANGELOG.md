# Changelog

All notable changes to ChalkBox will be documented in this file.

The project follows a lightweight form of [Keep a Changelog](https://keepachangelog.com/) and intends to use semantic versioning for tagged releases.

## [Unreleased]

### Added

- Open-source governance and maintainer documentation.
- Contribution and security guidance.
- Public project roadmap.
- GitHub issue and pull-request templates.

### Changed

- Package metadata updated to use the ChalkBox project name and an initial pre-1.0 version.

## Release process

For each tagged release:

1. move relevant entries from `Unreleased` into a dated version section;
2. verify build/lint/tests applicable to the release;
3. document breaking or configuration changes explicitly;
4. create a GitHub release with user-facing notes;
5. keep migration or rollback information where relevant.
